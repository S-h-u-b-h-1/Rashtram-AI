# Research Report Generation V1

Reports are private to the creating account and use only the selected documents'
passages that pass the shared evidence-sufficiency system. They include an
executive summary, research question, authorities, instruments, provisions,
timeline, comparison, implications, open questions, limitations, and complete
citation records.

Every evidence record preserves its citation ID, document ID and title, source
URL, page/section, and authority class. Report sections without verified support
display `Insufficient verified evidence.` The PDF export is private/no-store and
uses the same stored evidence identities rather than rerunning retrieval.
